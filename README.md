# ICS-MP — Matriz com indicadores do IEGM

`index.html` é uma página que apresenta a Matriz ICS-MP (REV05, 25 indicadores, 8 municípios) e propõe trocar os indicadores de baixo poder discriminatório por dimensões do IEGM (IRB/Atricon), para facilitar o diálogo com o TCE-MT.

- Seções: diagnóstico do poder discriminatório, o IEGM, as substituições, a matriz proposta, a coleta das notas IEGM (com entrada de dados), o resultado (ICS-MP atual × proposto) e as notas metodológicas.
- Os dados da REV05 estão embutidos na página. As notas IEGM novas (i-Fiscal, i-Planejamento, i-Cidade, i-Amb) são informadas na própria página, ficam salvas no navegador e podem ser exportadas em CSV.
- Para usar, basta abrir `index.html` no navegador.
